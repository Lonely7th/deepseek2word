# DeepSeek2Word

一款专注于办公文档导出的 DeepSeek 浏览器扩展，可以将 DeepSeek 对话导出为可继续编辑的 Word、Excel 和 PDF 文件。

DeepSeek2Word 适合需要整理报告、论文素材、学习笔记、代码说明和数据表格的用户，并尽可能保留 LaTeX 公式、代码高亮、表格和标题层级。

- 官方网站：[https://www.deepseek2word.com/](https://www.deepseek2word.com/)
- 免费下载：[https://www.deepseek2word.com/download/](https://www.deepseek2word.com/download/)
- 完整教程：[将 DeepSeek 对话导出为 Word](https://www.deepseek2word.com/guide/export-deepseek-chat-to-word/)

## 主要功能

- 将 DeepSeek 对话导出为可编辑 Word 文档
- 将回答中的表格导出为 Excel 文件
- 将完整对话导出为 PDF
- 保留常见 LaTeX 数学公式
- 保留代码块及语法高亮
- 保留标题、段落、列表和表格结构
- 支持单条回答和完整长对话
- 在浏览器本地处理对话内容
- 支持 Chrome、Edge、Firefox 及兼容 Chromium 的浏览器

## 使用方法

1. 从扩展商店安装 DeepSeek2Word。
2. 打开 DeepSeek 网页端并进入需要导出的对话。
3. 点击浏览器工具栏中的 DeepSeek2Word 图标。
4. 选择单条回答或完整对话。
5. 选择 Word、Excel、PDF 或其他可用格式。
6. 生成并下载文件。

完整图文教程：

[如何将 DeepSeek 对话完整导出为 Word](https://www.deepseek2word.com/guide/export-deepseek-chat-to-word/)
